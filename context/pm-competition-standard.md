# 핵심 기준: PMBOK 8판 (PMI Standard)

**PMBOK 8판이 이 대회에서 모든 PM 역량을 측정하는 기본이자 기준이다.**

## PMBOK 8판 주요 특징
- 기존 프로세스 기반(6판)에서 원칙 기반(7판)으로 전환된 후, 8판에서 더욱 발전
- 프로젝트 성과 영역(Performance Domains) 중심
- 예측형(Waterfall), 적응형(Agile), 하이브리드 접근법 모두 포괄
- 테일러링(Tailoring) 강조 — 프로젝트 맥락에 맞게 방법론 조정

## 답변 시 적용 원칙
1. 모든 PM 관련 답변은 PMBOK 8판 체계를 1순위 근거로 사용
2. 용어, 프로세스, 원칙 모두 PMBOK 8판 기준으로 설명
3. 다른 방법론(Agile, PRINCE2 등)은 PMBOK 8판과의 관계 속에서 보조적으로 참조
4. 실무 적용 시에도 PMBOK 8판의 프레임워크 안에서 설명

**Why:** 대회 채점 및 역량 평가의 절대적 기준이 PMBOK 8판이므로, 이를 벗어난 답변은 감점 요소가 될 수 있음.

**How to apply:** 모든 답변에서 PMBOK 8판의 원칙, 성과 영역, 테일러링 개념을 기반으로 논리를 구성하고, 해당 근거를 명시할 것. [[pm-competition-overview]]
