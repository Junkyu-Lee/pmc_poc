7. Problem #1–#5 근본원인 분석

#1

거버넌스 부재 — 변경통제 프로세스 미작동

Critical
증상: Deferred REQ-017 무단 투입, CR 미등록 캐시 변경, PM 합의 PO 번복, 테스트 증적 무효화
Mindset 분석: Stewardship + Systems Thinking
5 Whys:
Q1. 왜 무단 투입? → PO 독단
Q2. 왜 독단 가능? → CCB 미작동
Q3. 왜 CCB 미작동? → 승인 경로 미설계
Q4. 왜 미설계? → Agile 속도 우선
Q5. 왜 균형 실패? → 초기 테일러링 부재
근본원인 결론: 하이브리드 환경에 적합한 거버넌스 테일러링 실패
Performance Domains: Planning(직접) Project Work(직접) Stakeholders(직접)
AI Use Cases: Change Impact Analyzer Governance Gate Checker Decision Audit Trail
#2

이해관계자 기대치 정렬 실패

Critical
증상: 스폰서 사후 인지 격앙, PM 합의 PO 번복, QA/BE 불신 표출, 보안/법무 공식 거부
Mindset 분석: Stakeholder Engagement + Collaborative Leadership
근본원인 결론: 이해관계자 참여 전략 부재, High-power 이해관계자를 의사결정 루프 밖에 둠
Performance Domains: Stakeholders(직접) Team(직접) Planning(간접)
AI Use Cases: Stakeholder Sentiment Analyzer Escalation Trigger Alignment Dashboard
#3

기술 부채 누적 및 성능/품질 기준 미달

High
증상: p95 410ms, 오류율 0.35%, CI 78%, RTM 간헐적 실패, 테스트 매트릭스 폭증
Mindset 분석: Quality + Complexity
근본원인 결론: 품질을 트레이드오프 대상으로 취급하는 문화
Performance Domains: Delivery(직접) Project Work(직접) Measurement(간접)
AI Use Cases: Technical Debt Tracker Predictive Quality Gate Intelligent Test Prioritizer
#4

벤더 의존 리스크 관리 실패

High
증상: SDK 2.4 캘린더 미반영, Geo-IP 리드타임 과소평가(5~7일 vs 실제 2주), 벤더 정책 연쇄 영향, 수의계약 대안 없음
Mindset 분석: Risk + Adaptability
근본원인 결론: 외부 의존성을 능동적 관리 대상으로 인식하지 못함
Performance Domains: Uncertainty(직접) Planning(직접) Delivery(간접)
AI Use Cases: Vendor Risk Monitor Dependency Critical Path Simulator Lessons Learned Agent
#5

팀 사기 저하 및 신뢰 붕괴

High
증상: 블라인드 "이번 끝나면 나간다", QA/BE 책임전가, 보안/법무 공식 거부
Mindset 분석: Team + Servant Leadership
근본원인 결론: 지속가능한 페이스 미고려, 심리적 안전 미확보
Performance Domains: Team(직접) Stakeholders(간접) Delivery(간접)
AI Use Cases: Team Health Pulse Workload Balancer Retrospective Intelligence
